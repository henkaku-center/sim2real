# Two-eye design variant

Prompt: “Give it two eyes.” Generated by the same native V3 pipeline as
`../internal-frame-s3`, from `params.json` (base parameters plus `variant`):

```
PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib QT_QPA_PLATFORM=offscreen \
  /Applications/FreeCAD.app/Contents/Resources/bin/python -u -m tools.internal_frame_cad \
  --params assets/printing/internal-frame-s3-two-eyes/params.json \
  --output assets/printing/internal-frame-s3-two-eyes --include-bottom-cover
```

- The reference frame, bottom cover, head shell and lid are cut at Y = ±4.25 mm
  and their outer halves translated 15 mm apart (30 mm wider). The cut planes
  cross only faces that are straight along Y, so no hole, boss or curve is
  rescaled. The PCB, its pilots and spacers, the cover screws and the rear
  switch stay central; servo bays, head screws, ears and cable entries move out.
- The widened display aperture is closed in the middle with the wall's own
  section, leaving two 22.25 mm eyes at Y = ±15.1 mm, 30.3 mm apart, so two
  27.3 mm OLED modules fit side by side.
- Electronics: the second SSD1306 shares the I²C bus (S3 D17 SDA, E17 SCL) with
  the first OLED (0x3C) and servo hub; it must be set to address 0x3D. No new
  S3 pins are needed, but the carrier has one four-pin display header (M12–M15),
  so the second display needs a parallel header or a splitter lead, and a
  second display object in firmware.

Checked: valid closed solids, electronics/spacer clearances, head/frame screw
axes, cover fasteners, servo-bay preservation, lid capture and slide, battery
notch and switch opening. Not checked by this pipeline: authored ribbon routes
(they belong to the base frame datums), leg poses against the head, physical
print or fit.

Leg clearance is recorded separately in `leg-clearance.json`
(`uv run python tools/leg_clearance.py internal-frame-s3-two-eyes --write`): a
CAD-derived sweep of every hip and foot servo against this variant's own frame,
covers and lid. Walls and hip shafts both move out 15 mm, so the figures equal
the base kit's: 2.33 mm at rest and first contact with the head-cover side wall
13.0° toward the middle of the body. This directory has no recorded leg samples
or ribbon routes of its own; the legs are placed on its `hip_shaft_xy_mm` with
the base kit's leg datums. Nominal CAD, not a physical fit test.

## Regeneration time (measured 2026-11-12)

Regenerating this design from `params.json` and re-running every digital check
took **484 s** (8 min 4 s) on an Intel Core i7-8700B Mac, and left the working
tree byte-identical:

| Stage | Command | Time |
|---|---|---|
| CAD, exports and validation, no cache | the FreeCAD command above with `--fresh-checks` | 425 s |
| Leg clearance | `uv run python tools/leg_clearance.py internal-frame-s3-two-eyes --write` | 5 s |
| Dynamics twin | `uv run python -m sim.twin` | 2 s |
| Variant dynamics evidence | `uv run python -m sim.twin_evidence` | 34 s |
| Design check | `uv run python tools/check_design.py` | 18 s |

This is the digital part only. Printing, wiring a second display, assembly and
any physical test are not included and have not been done.
