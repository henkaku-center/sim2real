# Print files

## `sesame-legs-set.3mf`

One full set of Sesame legs (L1–L4, R1–R4, upstream v117 STLs), sliced in Bambu Studio 2.08
for the **P1S, 0.4 mm nozzle, Bambu PLA Basic**. Open it in Bambu Studio, choose **Print plate**
and pick the AMS slot for the colour you want. For several colours, print it once per colour.

- Settings from the upstream printing guide: 10% honeycomb infill, 2 wall loops, no supports;
  0.20 mm layers (Bambu "0.20mm Standard" process).
- Parts are auto-oriented flat (max height 20.4 mm).
- Estimate per set: **~1 h 13 min, ~32 g PLA**. Also fine for PLA Pure and PLA Matte.

The project file carries its full slicer settings, so reslicing for another printer or filament
only needs it opened in Bambu Studio.
