# 要件の整理 — Sesame 甲羅（bambu/）— 2026-11-05

`bambu/` の作業で、要件の拠り所はこの文書だけにします。README・HANDOFF・BREATH.md の要件の記述は、ここを参照してください。
**決めるのはユーザー（このロボットの持ち主）です。** §7 の未決定事項は、決まったら「決定」欄に日付と内容を書き込んでください。

## 1. 何を作っているか（2つの層）

| 層 | 内容 | 位置づけ |
|---|---|---|
| **A. 元の要件（自己復帰）** | 転倒しても甲羅の形で歩行姿勢に戻る | **必須**。最初の依頼（2026-10-29） |
| **B. 追加の要望（表現・研究）** | 呼吸する膜と口、環境が身体に「浸透」して外から見える振る舞いになる | **これも必須**（2026-11-05 Q1）。A と B の両方を満たす統合設計にする |

これまでの成果物のうち、**A を満たすのは V3版の甲羅（`stl/v3/`）だけ**です。Ø100 の縮小ドーム（`stl/test/`）と呼吸ドーム（`stl/breath/`）は、
A を満たしません（§5）。

## 5. 衝突の整理（B が A に与える影響）

| # | 衝突 | 理由（数値） | 整理案 |
|---|---|---|---|
| C1 | **Ø100 では自己復帰できない** | V3 では R ≥ 98（Ø196）が必要。R = 50 では横・前後の安定面が大きく残る | Ø100 は**机上の試作（形・印刷・呼吸機構の確認）に限定**し、A の対象外と明記する。本番は Ø196 |
| C2 | **天頂の窓**が、仰向けで止まる原因になる | 床が窓をまたぐと平らな面になる。V3 で開けてよい窓の半径は e·sin(θ − 8.5°) − 1.5 mm：θ = 30° で 5.8 mm、60° で 14.1 mm、80° で 17.5 mm、天頂では 0 | 窓は**θ ≥ 60°（半径 14 mm まで）か θ ≥ 80°（半径 17.5 mm まで）**の側面に置く。天頂は今のまま滑らかに |
| C3 | ふくらんだ膜が球面より外に出ると、転がる面の一部になる | 膜が支点になり、新しい止まり方ができる。押しつぶされて傷む | **転倒を検知したら息を止めて吐ききる**（膜を球面の内側に戻す）を要件にする。「息をのむ」という表現にもなる |
| C4 | 口と唇が転がる面に出る | C3 と同じ | 口を 10 mm ほど奥に下げる（呼吸ドームと同じ）。窓の大きさは C2 の規則に従う |
| C5 | 呼吸機構の質量で重心が上がる | ポンプ・カプセル・チューブ。高い位置ほど不利 | ポンプはフレームか蓋（低い所）に置く。質量を mass_model に入れて R と e を再計算する（R2） |
| C6 | 皮膚の厚さの指定が 3 種類ある | A1：骨格 3 mm＋皮膚 1 mm。A4：膜 0.3 mm。V3 本番：肉厚 1.2 mm。R98 を 3 mm で作ると数百 g になり、重心が上がって R13 が崩れる | 本番は肉厚 1.2 mm のまま。皮膚は 0.3 mm（光を通す・柔らかい）か 1 mm（丈夫）を**選ぶ**（§7 Q3）。3 mm は試作だけ |
| C7 | 取付けの場所が違う | 呼吸ドームは蓋に、V3 甲羅はブラケットに付く | 本番では、呼吸のカプセルを**甲羅の内面の窓に直接付け**、ポンプは蓋に置いてチューブでつなぐ |
| C8 | 脚の可動域 | カプセルや台座が脚の掃引範囲に入ってはいけない | 統合したら FCL のすき間チェックをやり直す（R3） |
| C9 | 研究用センサー | IMU は R7（転倒検知）でも必須。マイク・ガス・気圧は質量と電力が増える | まず IMU だけ。ほかは研究段階で追加する |
| C11 | 動きをポンプにすると、脚がポンプ機構に触れる（意図した接触） | R3 は「歩行を妨げない」こと。ポンプの反力はサーボの負荷になる（MG90S の公称 0.176 N·m） | ポンプの反力によるトルクを制限する（例：0.03 N·m 以下、§6 E7）。walk の脚軌道と速度が変わらないことを数値で確認する |
| C12 | 動かないと呼吸が止まる | 待機中は脚が止まっている | 待機中は「呼吸の動き」として脚を小さく往復させる（カメも休息中に四肢を動かして換気する）。これが歩行を妨げないこと |
| C10 | トリックが甲羅に当たる | dance / point / cute / shrug（wave は 2.0 mm で余裕が足りない） | 「驚いて隠れる」などの表現は、トリックではなく**畳み姿勢**を使う |

## 6. 統合した要件（v2。2026-11-05 の決定 Q1〜Q4 を反映）

A（R1〜R15）は**変えない**。B も必須なので、次の要件を A と**同時に**満たす設計にします。

| ID | 要件 | 判定方法 |
|---|---|---|
| E1 | 呼吸：膜と口を**自己復帰甲羅（Ø196）の側面**に付ける。窓は C2 の規則を守る | 静的解析で単安定のまま（重心 ±3 mm でも） |
| E2 | 転倒中・復帰中は膜を球面の内側に戻す（息を止める・吐ききる） | 畳み姿勢で膜の高さ ≤ 0。E7 では、**畳む動き＝膜が吸い込まれる向き**になるようにポンプの向きを決めれば、機構だけで満たせる |
| E3 | 呼吸機構の質量と位置を mass_model に入れ、R と e を再設計する | design.py の反復が収束し、R1〜R15 を再判定して合格 |
| E4 | 状態から症状への写像：最初は IMU だけで、転倒・揺れ → 呼吸パターン（平常・浅く速い・息を止める）を変える | 呼吸パターンを数値で記録する（回数/分、深さ） |
| E5 | Ø100 の試作品（`stl/test/`、`stl/breath/`）は**机上の試験専用**で、R の対象外 | 文書にそう明記されていること |
| E6 | 研究構想（A5）は後の段階で扱う：環境の舞台（酒場・高地・海・雑踏・岩場）、外皮セルを画素として使う、慣れ・過敏化 | 別の文書で研究計画にする |
| E7 | **空気源は追加のアクチュエータを使わず、ロボットの動きそのものをポンプにする**（Q4）。カメが四肢の動きで肺を換気するのと同じ考え方。歩けば呼吸が速まり、畳めば「シューッ」と息が抜ける | 決まった脚の動き 1 回で、膜の高さを所定の範囲（例：8〜20 mm）に動かせる。そのときポンプの反力によるトルクは 0.03 N·m 以下で、walk の脚軌道が変わらない（C11） |
| E8 | 外皮の膜は 0.3 mm（Q3）。外皮セルを画素として使う構想に合わせる | V3 版のくぼみ 178 個、膜厚 0.28〜0.34 mm（CAD）。試し刷りで残るか確認する |
