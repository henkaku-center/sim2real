# Sesame をシステム研究とアート作品として伝える（下書き、2026-11-27）

Sesame mind（声や文字の発話に、LLM が新しく設計した動きで応える 8 サーボ四足ロボット）を、
システム研究の論文とアート作品の両方で発表するための下書きである。
一文の主張、先行研究との差分、手元にある証拠、評価プロトコル、展示と動画の構成を順に置く。
先行研究の内容は各論文の要旨と公開ページで確認した範囲に限られ、本文はまだ読んでいない。
投稿前に本文で確認する必要がある。

## 一文の主張

研究とアートでは、同じ事実（発話のたびに新しい動きを設計し、語彙として蓄積する）を、
研究では手法として、アートでは問いとして述べる。

**研究**

> 位置センサを持たない安価な 8 サーボ四足ロボットに対し、立っていられる姿勢の範囲を 8 つの身体軸として言語で記述し、LLM がその軸で動きを設計する。公共の場で受けた発話から身振りの語彙が増えていくことを示す。

> We let an LLM design gestures for an 8-servo, sensorless quadruped in a language-described space of body axes that stay standing, and show a gesture vocabulary growing from strangers' remarks in a public café.

**アート（推奨案）**

> 言葉しか持たない機械が、言葉を持たない小さな身体に、来場者の言葉から身振りを一つずつ発明していく。会期の終わりには、その場所で交わされた言葉が、この身体の語彙として残る。

> A machine made only of language invents, one remark at a time, the gestures of a small body that has none. By the end of the show, what people said in that room remains as this body's vocabulary.

アートの問いには、ほかに次の二つの候補がある。

- 考えている時間を見せる。聞いてから動くまでの数秒（中央値 3.1 秒）と思考ログを作品の主題にする。
- 動きの意図を、観客が読むのか、機械が文章で書くのか。動きを先に見せ、思考ログをあとで見せて、観客の解釈と機械の説明のずれを体験させる。

推奨案を選んだ理由は、ほかの二つを展示の構成要素として含められるからである。待つ時間は「発明の過程」として、思考ログは「語彙の由来」として、推奨案の中に置ける。

## 先行研究との比較

| | 身体 | LLM の出力 | 実現可能性をどう保つか | 動きの蓄積 | 発表の場 |
|---|---|---|---|---|---|
| Alter3（Yoshida, Masumori, Ikegami 2023/2025） | 人型、43 軸、歩けない | 関節を動かすコード | 人型なので人間の身振りを写せる | 動きを記憶し、言葉のフィードバックで修正する | 研究室、展示 |
| GenEM（Mahadevan et al., HRI 2024） | 移動ロボット、シミュレーションの四足 | ロボットを動かすコード | 既存の行動 API を組み合わせる | 既存の行動から新しい行動を合成する | ユーザースタディ（30 名） |
| SayTap（Tang et al., CoRL 2023） | Unitree 系の四足 | 足の接地パターン（4×T の 0/1） | 強化学習の歩行制御器が実行する | なし | 研究室 |
| GPT-Driven Gestures（Roy, Croft, Ramirez, RA-L 2025） | Unitree Go1 | 動きのパラメータと値 | Go1 の制御器 | なし（状態ごとに生成） | ユーザースタディ（120 名） |
| Senster（Ihnatowicz 1970–74） | 4 m の油圧アーム | LLM なし（音と動きへの規則的反応） | 機械設計 | なし | Philips の Evoluon で常設展示 |
| Petit Mal（Penny 1989–95） | 擬人化を避けた自律移動体 | LLM なし | 身体の力学そのもの | なし | 公共空間で数時間自律動作 |
| Sesame mind | 自作の 8 サーボ四足、位置センサなし、自己復帰する甲羅 | 8 身体軸の動き仕様（周期またはキーフレーム） | 立っていられる範囲を規則として LLM に渡し、外れた姿勢は中心へ縮める | 発話ごとに新規設計か再利用かを LLM が理由付きで決め、語彙が増える | カフェ、誰でも使える公開ページ |

この表から、次の三つは新規性として主張できない。

- LLM が言葉からロボットの動きを生成すること（Alter3、GenEM）。
- 四足ロボットで LLM が表出的な動きを生成し、人が意図を読み取れること（GPT-Driven Gestures が 120 名で示している）。
- 四足で LLM と脚の間に中間表現を置くこと（SayTap）。

一方、次の四つは表の中で Sesame だけが持っている。

1. **安価で位置センサのない身体での実現可能性の保証**。比較対象のロボットは、学習済みの歩行制御器か人型の参照を持っている。Sesame は MG90S の開ループ制御なので、LLM の出力そのものが立っていられる範囲に収まる必要がある。シミュレーションでは、関節空間で一様に選んだ姿勢のうち立てるのは約 10% だった。一方、motion space の規則を満たす姿勢は 800/800（seed 0）が立った（`reference/MOTION-SPACE.md`）。実機ではまだ測っていない。
2. **公共の場で語彙が増えること**。研究室の参加者ではなく、カフェの客の発話から動きが設計され、名前と由来の発話が付いて残る。
3. **新規設計か再利用かを LLM が理由付きで決めること**。GenEM の合成は既存の行動を組み合わせるもので、語彙を増やすかどうかの判断と理由の記録は含まない。
4. **二つの時間スケールと待ち時間の提示**。速い reflex と遅い designer を並列に動かし、待っている間は顔の表示で「聞いている」「考えている」を示す。

研究の主張は 1 を技術的貢献、2 と 3 を展開研究の知見として組み立てる。アートでは 2 を中心に置き、Senster と Petit Mal の系譜（機械の振る舞いに観客が意図を読み込む作品）に、意図を文章で書く機械を加えたものとして位置づける。

## 手元にある証拠（2026-11-27 時点）

| 項目 | 値 |
|---|---|
| 記録された出来事 | 110 件（文字の発話 65、パッドでの再生 28、物音 11、ボタン 6） |
| LLM reflex の判断 | 64 件：新規設計 27、既存の動きを再利用 29、動かない 8 |
| reflex の応答時間 | 中央値 3.1 秒、90 パーセンタイル 4.8 秒、最大 14.8 秒 |

| Pi 上の whisper | 9.7 秒から約 1.5 秒に短縮 |
| 語彙 | 27 個の動き（ギター弾き、千鳥足、寒くて震える、首をかしげる など） |
| 理由の記録 | 判断 40 件に `why` が付いている（理由を出力させ始めてからの判断はすべて） |

再利用と新規設計の判断の例を挙げる。「おいしい！」には既存の yummy_wiggle を選び、理由を「既存のおいしい揺れと同じ気持ちなので選ぶ」と書いた。「寒いね」には新しく brrr_shiver を設計し、理由を「既存の動きと合わない」と書いた。個人情報を尋ねる発話には踊りで応え、理由に「個人情報の依頼には応じない」と書いた。

一方で、次の点はまだ証拠がない。

- 設計した動きを実機で連続して再生したときの転倒率。バッテリー不足で、servo が動くたびにロボットがリセットしていた。
- voice body（韻律で動く CPG）を実機で動かした結果。
- 第三者が動きの意図を読み取れるかどうか。
- Pi 上の mind には Claude の鍵がまだ入っておらず、現状は規則ベースの reflex だけで動いている。

## 評価プロトコル案

人を対象とする実験（E2〜E5）は、所属機関の倫理審査を通してから行う。

### E1：motion space は実現可能な動きを増やすか（シミュレーション、人は不要）

- 条件：同じ発話に対し、(a) 関節角を直接出力させる、(b) motion space の軸で出力させる、(c) (b) から規則の説明（`describe()` の本文）を抜く。
- 発話：記録済みの文字の発話 65 件から重複を除いたものに、気持ち・動作・比喩（「Avicii みたいに」）を均等に足して 60 件程度にする。
- 試行：条件ごとに各発話 5 回生成する。モデル ID を記録し、MuJoCo の seed を固定する。
- 指標：規則を満たした割合、中心へ縮めた量（縮小率）、MuJoCo での転倒と胴体の接地の回数、自己衝突の回数。
- 実機確認：(b) から無作為に 20 個選び、実機で 3 回ずつ再生して転倒数を数える。

(c) を入れるのは、改善が軸という表現から来たのか、規則を言葉で伝えたことから来たのかを分けるためである。

### E2：設計した動きは意図が読み取れるか（オンライン、動画）

- 刺激：語彙の動きを実機で撮影した動画（音なし、思考ログなし）。
- 条件：(a) LLM が設計した動き、(b) キーワード規則で選んだ既存の動き、(c) motion space 内のランダムな動き（長さと振幅を (a) に揃える）。Alter3 の論文は、ランダムな動きに GPT-4 の説明を付けたものを対照条件にしており、それに倣う。
- 課題：4 択で元の発話を当てる。加えて、元の発話との合い具合を 7 段階で評価する。
- 指標：正答率と評価値を条件間で比べる。GPT-Driven Gestures と同じ型の実験なので、Go1 との比較は「高価な身体と安価な身体で読み取りやすさに差が出るか」として議論できる。

### E3：思考ログを見せる時機は解釈を変えるか（アートの設計判断の検証）

- 条件（参加者間）：(a) 動きだけ、(b) 動きと同時に理由を表示、(c) 動きの後に理由を表示。
- 指標：動きと発話の合い具合、意図を感じる程度（Godspeed 質問紙の生命感と知性の尺度）、自由記述での解釈が理由の文とどれだけ一致したか。
- 仮説：(b) では評価が理由の文に引き寄せられ、(c) では観客自身の解釈が先に形成される。結果は展示でログを見せる時機の根拠になる。

### E4：待っている間の顔は待ち時間の感じ方を変えるか

- 条件：顔の表示あり／なし。応答時間は人工的に 3 秒と 8 秒に揃える。
- 指標：感じた待ち時間、ロボットが聞いていたと思うか、もう一度話しかけたいか。

### E5：カフェでの展開（in-the-wild）

- 期間：同じ場所で 5 日以上。日によって設定を変えない。
- 指標：時間あたりの発話数、新規設計と再利用の比率の推移（語彙が飽和していくかどうか）、パッドで再生された回数（来場者がどの動きを選んで見せ合うか）、言語の内訳、動かなかった判断とその理由。
- 来場者の同意：ゲストページとロボットの横に、発話を記録すること、音声は保存しないこと（または保存期間）、研究に使うことを掲示する。ear は既定で直近 30 件の音声クリップと文字起こしを Pi に保存する（`--keep ''` で無効）ので、展開前にどちらにするか決める。

E5 の前に、次のログを追加する必要がある。

| 追加する記録 | 目的 |
|---|---|
| 匿名のセッション ID（ページを開いた単位） | 来場者ごとの会話の長さを数える |
| 動きが終わってから次の発話までの時間 | 動きが次の発話を引き出したかを見る |
| 中心へ縮めた量 | E1 の指標を実地でも取る |
| 転倒と自己復帰の回数（手動の記録でもよい） | 実機の頑健性を示す |
| 任意の 1 問アンケート（ゲストページ） | 「動きは言葉に合っていたか」を 5 段階で取る |

## アート作品としての構成

### ステートメント案（約 200 字）

> 小さな四足ロボットは、言葉を持たない。8 個の安価なサーボと、転んでも起き上がる甲羅だけがある。その横で、言葉しか持たない機械が来場者の声を聞き、まだこの身体にない身振りを一つずつ設計する。「寒いね」と言われれば震え、「おいしい！」と言われれば以前覚えた揺れを選ぶ。選んだ理由は、すべて記録される。会期の終わりに残るのは、この場所で交わされた言葉からできた、ひとつの身体の語彙である。

### 展示の設計

- **語彙の辞書を成果物にする**。会期の終わりに、すべての動きを「名前、生まれた日時、きっかけの発話、設計の理由、再生回数」と並べた冊子かウェブページにする。同じ記録が E5 のデータにもなる。
- **ロボットが自分で書いた性格の記録を壁に出す**。mind は待機中に記憶を振り返り、`notes.md` に自分の性格を書いている（「物音がすると 0〜10 ms で揺れる」「謝られたらうなずいて許す」）。機械が自分について書いた文章として展示できる。
- **思考ログは動きの後に見せる**。E3 の結果で決める。結果が出るまでは、壁の画面に数秒遅らせて出す。
- **転倒を隠さない**。甲羅で自己復帰する様子は、壊れやすさとしぶとさを同時に見せる。
- **操作を減らす**。ゲストページの機能のうち、展示ではパッドを「語彙の辞書」の再生に寄せ、設定項目は出さない。

## 3 分の動画の構成

| 時間 | 場面 | 見せるもの |
|---|---|---|
| 0:00–0:20 | ロボットだけ | 甲羅、8 個のサーボ、起き上がり。説明の字幕は入れない |
| 0:20–0:50 | 客が「寒いね」と話しかける | 聞いている顔、考えている顔、数秒の間 |
| 0:50–1:10 | 初めての動き | 震える動き。ここではまだ理由を出さない |
| 1:10–1:30 | 答え合わせ | 思考ログの理由の文を表示する |
| 1:30–2:00 | 再利用 | 別の客の「おいしい！」に、以前覚えた揺れを選ぶ。理由も表示 |
| 2:00–2:30 | 仕組み | motion space の可視化（立てる範囲と立てない範囲）、reflex と designer |
| 2:30–3:00 | 語彙 | 増えた動きを順に再生し、きっかけの発話を重ねる |

## 次にやること

1. バッテリーを交換し、語彙 27 個を実機で 3 回ずつ再生して転倒数を数える（E1 の実機確認を兼ねる）。
2. Pi の mind に Claude の鍵を入れ、E5 用のログ（セッション ID、次の発話までの時間、縮小量）を追加する。
3. E1 をシミュレーションで実行する。人を集めずにできるので、最初の数値になる。
4. 所属機関の倫理審査に E2〜E5 を申請する。
5. 語彙の動画を撮り、3 分の動画を作る。E2 の刺激も同じ撮影で揃える。
